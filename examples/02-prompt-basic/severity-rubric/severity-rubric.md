# Severity Rubric

Classify each reported issue into exactly one of the following severity levels.

## Levels

- Critical: breaks core functionality or causes data loss
- High: significant impact on usability or correctness
- Medium: noticeable issue with a workaround
- Low: cosmetic or minor inconvenience

## Rules

Assign the highest level whose description matches the observed impact. When two levels fit equally well, choose the lower one and explain the trade-off in one sentence.
